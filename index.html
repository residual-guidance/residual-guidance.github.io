Streaming video models often keep generating the old prompt after the user changes it. We trace this to the cached frames themselves and propose Residual Guidance, a training-free correction that adds one forward pass per chunk.

Abstract

Real-time interactive video generation allows users to change the prompt during generation to steer the evolving video. However, existing streaming models, which generate videos chunk by chunk, often keep following the previous prompt after a switch. We trace this failure to context inertia, where the previous chunk acts as a strong prior that suppresses the new prompt. Furthermore, we find that this inertia persists even when the cache retains only the previous chunk, yet discarding the context breaks visual continuity, which limits approaches that edit the cache. Rather than editing the cache, we propose Residual Guidance (RG), a simple, training-free method that counteracts context inertia with a correction measured outside the cache. Specifically, RG denoises the re-noised previous chunk once under the new prompt without the cache and adds the resulting residual to the early denoising steps of the next chunk, where its content is largely decided and the new prompt is most suppressed. Across settings ranging from a single switch to long multi-switch generation, RG substantially improves prompt switching capability on existing streaming models, including those with dedicated switching mechanisms, while largely retaining visual quality. As it requires no training or per-model tuning and adds only one forward pass per chunk, RG can be easily integrated into existing real-time video generation pipelines.

Summary

Problem
When the prompt changes mid-stream, the new prompt often never shows up. On 100 switches, 80% (Self Forcing) and 64% (LongLive) are never realized within 5 s.
Cause
The cached frames, not stale prompt information, suppress the new prompt. With the full cache only 18% of the context-free prompt response remains, a single cached chunk is already enough to suppress it, and the effect is strongest at the first denoising step.
Method
Re-noise the previous chunk, denoise it once under the new prompt with an empty cache, and add the difference to the next chunk's prediction at the first two denoising steps. The cache itself is not modified, so it works on top of any cache strategy.

Context Inertia

To see why switches fail, we fix the noisy input of the switch chunk and measure how much the new prompt moves the prediction under a visible context \(\mathcal{C}\), relative to how much it moves it with no context at all.

\[ \rho(\mathcal{C}) = \frac{\lVert \hat{x}(\mathcal{C}, y_\text{new}) - \hat{x}(\mathcal{C}, y_\text{old}) \rVert}{\lVert \hat{x}(\varnothing, y_\text{new}) - \hat{x}(\varnothing, y_\text{old}) \rVert} \]

Relative prompt response \(\rho\) at the first denoising step. LongLive is re-cached under the new prompt before measuring.

The cached content suppresses the new prompt. Even a single cached chunk removes most of the prompt response, and since LongLive is re-cached first, stale prompt information is not the cause. Removing the context entirely does realize the switch, but changes the subject and background.

It is strongest at the first step. Without context, the prompt switch changes the clean prediction by 0.62 (relative to \(\lVert s_{k-1} \rVert\)) at step 1, but only 0.19 at step 2 and 0.03 at step 4. This suggests measuring the prompt signal without the cache and applying it early.

Method

Residual estimation. The previous chunk \(s_{k-1}\) is re-noised to level \(\tau\) and denoised once under the new prompt with an empty KV cache. Its difference from the original chunk is the residual:

\[ r_k = \hat{x}_\theta\big(\tilde{x}^{\tau}_{k-1} \,\big|\, \varnothing,\, y_\text{new}\big) - s_{k-1} \]

Because no cache is involved, the residual is not suppressed by context inertia. It moves away from the previous content and toward the new prompt. The noise level \(\tau\) controls its strength, similar to a guidance scale.

Residual injection. The residual is added to the cache-conditioned prediction of the next chunk at the early denoising steps:

\[ \hat{x}^{(i)}_k = \hat{x}_\theta\big(x^{t_i}_k \,\big|\, \mathcal{C}_{<k},\, y_\text{new}\big) + \lambda_i\, r_k \]

With \(\lambda = (1, 0.5, 0, 0)\), the later steps run unchanged with the full cache, which keeps the subject and scene consistent. We use τ = 850 for every model, and since the cache is untouched, RG combines with re-caching, cache flushing, anchors or memory retrieval.
